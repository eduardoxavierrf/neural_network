# Rede Neural do Zero

Este repositório contém uma implementação de uma rede neural simples construída do zero, utilizando apenas **Numpy** e conceitos matemáticos básicos para resolver o problema do **MNIST dataset** (reconhecimento de dígitos manuscritos).

O principal objetivo deste projeto é **entender profundamente como uma rede neural funciona**, sem camadas de abstração fornecidas por frameworks como TensorFlow ou PyTorch.
